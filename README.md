# وب‌سایت شخصی مهدی باخدازاده

نسخه تک‌صفحه‌ای بهینه‌شده برای موتورهای جستجو.

## ساختار
- `index.html` — صفحه اصلی (تک‌صفحه‌ای)
- `assets/css/` — استایل ماژولار (variables, base, layout, components)
- `assets/js/main.js` — اسکرول‌ریویل
- `assets/images/` — تصویر پروفایل
- `components/` — قطعات آماده برای مهاجرت بعدی
- `data/site.json` — داده‌های ساختاریافته
- `seo/` — robots, sitemap, verification
